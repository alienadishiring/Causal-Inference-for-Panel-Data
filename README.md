# Causal Inference for Panel Data

This repository contains the teaching material of the workshop on Causal Inference for Panel Data, a course I designed for PhD students and participants to the Winter School on [Causal Inference with Machine Learning](https://southcoastdtp.ac.uk/events/winter-school-with-the-expert-causal-inference-with-machine-learning/). 

## Overview:


This workshop focuses on the use of panel data for causal inference from an applied perspective. 

On the [first day](https://github.com/alienadishiring/Causal-Inference-for-Panel-Data/blob/main/Day%201.pdf), it will provide an overview of the most up-to-date econometric techniques for analysing panel data, with particular emphasis on the Difference-in-Differences method. It will also introduce some well-known UK longitudinal datasets (e.g., Understanding Society) and discuss key issues and precautions to consider when working with complex survey data.

The [second day](https://github.com/alienadishiring/Causal-Inference-for-Panel-Data/tree/main/Hands-on) will be dedicated to a lab session in which participants will learn how to apply the techniques discussed using Stata. In the first part of the session, students will complete a guided problem set. The second part will be autonomous, although participants will have the opportunity to interact with and receive support from the instructor.


## Learning Outcomes:

### Subject Specific Intellectual and Research Skills:

· Identify issues that could bias causal estimates

· Identify proper econometrics techniques to address those issues

· Analysis of complex longitudinal data

· Use Difference-in-differences estimation techniques

### Knowledge and Understanding:

· Econometrics techniques for causal inference

### Transferable and Generic Skills:

· Answer specific research questions by using appropriate techniques for causal inference

· Good practices in writing reproducible code


## Syllabus

The main topics to be covered include:

(1) Definition of panel data

(2) Econometrics techniques for causal inference using panel data

(3) Focus on Difference-in-differences (overview of the most up-to-date literature and techniques)

(4) Challenges and good practices in analysing complex longitudinal survey data

(5) Hands on: analysis of complex longitudinal datasets using Stata (guided)

(6) Hands on: analysis of complex longitudinal datasets using Stata (autonomous)
